# Food Ordering Microservices

Food ordering backend built with Spring Boot microservices.

## Services
- Product Service: manages menu items
- Order Service: places orders
- Inventory Service: checks stock

## Tech
Java, Spring Boot, MySQL, Docker, JUnit, REST Assured, WireMock

## Run
1. Start MySQL with `docker-compose up`
2. Run each service from its folder with `mvnw spring-boot:run`
